# CRED App FrontEnd

A premium fintech landing page inspired by the CRED brand, built as a single-page frontend experience using HTML, CSS, and React via CDN.

## Overview

This project recreates a polished, dark-themed CRED-style landing page with:

- a hero section with premium branding
- trust and member-focused messaging
- feature cards for rewards, payments, and credit score tools
- animated counters and scroll reveal effects
- security and trust sections
- a premium footer and modern UI styling

## Project Structure

```text
CRED-App-FrontEnd-/
├── CRED/
│   └── index.html
└── README.md
```

## Run Locally

Since this project is a static frontend, you can run it by opening the file directly in a browser:

1. Navigate to the `CRED` folder.
2. Open `index.html` in your browser.

You can also serve it locally with a simple static server, for example:

```bash
cd CRED
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Tech Stack

- HTML5
- Tailwind CSS CDN
- React 18 via CDN
- Babel standalone
- JavaScript
